Tonal Export

A personal workout-data export and archiving utility, with optional backup of prepared reports to the owner’s Google Drive.

This is an information site, not a workout dashboard. It does not display personal training records, accept file uploads, or provide a sign-in form.

What the utility does

Tonal Export runs on a server controlled by its owner. It retrieves the owner’s Tonal training history, validates the export, and prepares recent-training reports and historical archives for personal review.

Reports can include exercises, sets, repetitions, resistance, workout dates, training volume, and available strength or readiness metrics. These records remain separate from this public website.

When the Google Drive integration is configured and authorized, the utility uses rclone to create and update a dedicated folder of approved reports in the owner’s Drive. It does not make those files public.

Why Google Drive access is requested

Drive access supports private report backup and access from the owner’s other devices. The integration is designed to request only the per-file scope https://www.googleapis.com/auth/drive.file, not access to the entire Drive.

In this configuration, rclone works with the files and folders created through this application. See rclone’s scope documentation and Google’s Drive permissions documentation.

Who this is for

This is a single-user personal project maintained by the GitHub account cdcoulson. It is not a public hosted service and does not accept registrations from other users.

Google authorization is performed through Google’s OAuth consent flow during local configuration. This website never asks for a Google password, Tonal password, OAuth token, or client secret.

Privacy and control

The privacy policy explains the data used by the utility, local and Drive storage, optional sharing, retention, and how to revoke access. No personal workout exports or authentication files belong in this website’s repository.

For non-sensitive questions about this project, use the repository issue tracker. Issues are public: do not post private training data or credentials.
